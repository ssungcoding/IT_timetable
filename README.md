# 근로시간표 만들기

3~10명의 수업시간을 입력하면 월~일 근로시간표와 대기시간표를 만드는 웹앱입니다.

GitHub Pages: https://ssungcoding.github.io/sw_timetable/

## 실행

Node.js 22 이상이 설치된 터미널에서 아래 명령을 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 사용 순서

1. 월요일부터 일요일까지 07:00~22:00 중 실제 운영할 30분 칸을 먼저 색칠합니다. 12:00~13:00도 필요할 때 선택할 수 있습니다.
2. 근로 인원 3~10명과 학생별 최소 출근 요일 수를 선택하고 이름을 입력합니다.
3. 공용 드롭박스에 학생 시간표 사진 3장부터 10장까지 한꺼번에 놓습니다. 사진 수에 맞춰 인원이 설정되고, 확장자를 제외한 각 파일명이 학생명으로 자동 입력됩니다. 수업·일정이 있는 30분 칸을 직접 클릭해 수정할 수도 있습니다.
4. `시간표 자동 생성`을 누릅니다.
5. 추천된 20개 후보 중 원하는 안을 선택합니다.
6. 근로시간표와 대기시간표를 확인하고 `엑셀로 저장`을 누릅니다.

추천 후보를 고른 뒤 `이 시간표 선택하고 수정`을 누르면 가능한 학생 드롭다운으로 근로표를 바꿀 수 있습니다. 근로표 수정을 마치고 `수정 완료 · 대기표 재생성`을 누르면 변경된 본 근로자를 기준으로 대기시간표가 공정하게 다시 계산됩니다. 이후 `대기표 수정`을 누르면 본 근로자와 수업 중인 학생을 제외한 가능한 학생만 골라 대기표도 수정할 수 있으며, 개인별 요약과 엑셀 저장에도 최종 결과가 반영됩니다.

선택한 최소 출근 요일 수를 먼저 맞춘 뒤 학생별 주간 근로시간 차이, 출근 요일 수 차이, 전체 출근 횟수 순으로 후보를 정렬합니다. 선택값은 고정 출근일이 아니라 하한선이므로, 해당 일수만으로 근로시간을 맞출 수 없으면 더 많은 요일로 자동 확장됩니다. 대기시간표는 본 근로자와 수업 중인 학생을 제외한 뒤 주간 전체를 한 번에 계산해, 가능한 칸을 최대한 채우면서 학생별 대기시간 편차가 최소가 되도록 배정합니다.

사진 인식은 월~금 열과 9시 이후 시간 행이 보이는 주간 시간표 캡처의 색상 블록을 읽습니다. JPEG, PNG, WebP를 지원하며 사진은 외부 서버로 전송되지 않습니다. 자동 인식 후에는 색칠된 표를 반드시 한 번 확인하고 필요한 칸을 직접 수정할 수 있습니다.
